# MOZPLAY Arena

A modern, mobile-first React + Tailwind single-page landing page prototype for **MOZPLAY Arena**, Mozambique's emerging esports and gaming event concept.

## Highlights

- Afro-futuristic premium esports visual direction
- Dark neon palette with purple, cyan, and orange accents
- Glassmorphism cards, animated network/map effects, and responsive sections
- Event chapters for Tete, Maputo, and Beira
- Concept leaderboard, tournament path, future legacy timeline, safety trust section, and sponsor opportunities

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
